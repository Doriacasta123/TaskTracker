# ✅ TaskTracker 📅

## ✨ What's This All About?

Welcome to **TaskTracker** — a minimalist and intuitive task manager where you can add, check off, and delete your daily tasks. It also tracks your overall progress visually so you stay motivated and organized!

---

## 🔎 Features

- 📝 **Add new tasks** with a due date  
- ✅ **Mark tasks as completed** by clicking on them  
- ❌ **Delete tasks** with a simple button  
- 📊 **Real-time progress bar** showing your completion percentage  
- 🎯 Clean and responsive user interface

---

## 🛠️ Tech Stack

- **HTML** – Page structure  
- **CSS** – Styling and layout  
- **JavaScript** – App logic and interactivity
